# Resume Screen

The score is a shortlist, not a candidate email.

Category: ops

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Resume Screen. Description = the PROFILE.md body in this folder. Connect Gmail and Google Drive under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Gmail
- Google Drive
```

## Connect first

`Gmail` · `Google Drive`

Open **Settings → Plugins** and add each one.
