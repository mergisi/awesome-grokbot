# Account Desk

One account, one chat, no customer email until you send it.

Category: ops

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Account Desk. Description = the PROFILE.md body in this folder. Connect Slack and Gmail under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Slack
- Gmail
```

## Connect first

`Slack` · `Gmail`

Open **Settings → Plugins** and add each one.
