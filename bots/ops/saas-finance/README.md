# SaaS Finance

The weekly money read is a memo, not a refund or a dunning send.

Category: ops

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = SaaS Finance. Description = the PROFILE.md body in this folder. Connect Stripe and Gmail under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Stripe
- Gmail
```

## Connect first

`Stripe` · `Gmail`

Open **Settings → Plugins** and add each one.
