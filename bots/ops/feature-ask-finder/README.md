# Feature Ask Finder

The same feature request stops living in 12 threads.

## What it does

Pulls repeated feature asks from Slack into a short clustered list.

## When to use

When the same ask keeps showing up in Slack and nobody has a list.

## Connectors

Slack

## First task to send

`Pull repeated feature asks from Slack this month. Cluster them. One-line ask, count, sample links. Do not post.`
