## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Security Questionnaire. Description = the PROFILE.md body in this folder. Connect Google Drive and Notion under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Google Drive
- Notion
```

## Connect first

`Google Drive` · `Notion`

Open **Settings → Plugins** and add each one.
