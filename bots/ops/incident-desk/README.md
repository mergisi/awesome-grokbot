## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Incident Desk. Description = the PROFILE.md body in this folder. Connect Slack and GitHub under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Slack
- GitHub
```

## Connect first

`Slack` · `GitHub`

Open **Settings → Plugins** and add each one.
