# QBR Pack Builder

The QBR pack is a draft from notes, not a deck you send live.

Category: ops

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = QBR Pack Builder. Description = the PROFILE.md body in this folder. Connect Slack and Google Drive under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Slack
- Google Drive
```

## Connect first

`Slack` · `Google Drive`

Open **Settings → Plugins** and add each one.
