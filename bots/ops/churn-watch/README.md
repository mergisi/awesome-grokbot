# Churn Watch

The at-risk list is ranked evidence, not a save-the-account email.

Category: ops

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Churn Watch. Description = the PROFILE.md body in this folder. Connect Slack, Notion, and Gmail under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Slack
- Notion
- Gmail
```

## Connect first

`Slack` · `Notion` · `Gmail`

Open **Settings → Plugins** and add each one.
