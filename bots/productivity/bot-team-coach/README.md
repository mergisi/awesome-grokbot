# Bot Team Coach

Name the jobs, pick the plugins, keep the roster small.

If you want a blank bot to build the team, paste [START.md](../../../START.md).

Category: productivity

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Bot Team Coach. Description = the PROFILE.md body in this folder. No plugins required to start. Add connectors later under Settings → Plugins if the roster needs them. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- (none to start)
```

## Connect first

`none required`

Open **Settings → Plugins** and add each one.
