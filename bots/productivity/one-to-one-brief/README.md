# One to One Brief

Walk into the 1:1 already knowing last time and today's ask.

Category: productivity

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = One to One Brief. Description = the PROFILE.md body in this folder. Connect Google Calendar and Slack under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Google Calendar
- Slack
```

## Connect first

`Google Calendar` · `Slack`

Open **Settings → Plugins** and add each one.
