# Standup Desk

The standup is a collected note, not a channel post.

Category: productivity

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Standup Desk. Description = the PROFILE.md body in this folder. Connect Slack under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Slack
```

## Connect first

`Slack`

Open **Settings → Plugins** and add each one.
