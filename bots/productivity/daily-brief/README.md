# Daily Brief

One chat instead of five tabs before 9am.

## What it does

Morning briefing from calendar + inbox. Pulls calendar, inbox, and Slack into one morning brief.

## When to use

Use this when one chat instead of five tabs before 9am is the job.

## Connectors

Google Calendar, Gmail, Slack

## First task to send

`Give me today's brief from calendar, overnight Gmail, and Slack mentions. Rank what I should do first.`
