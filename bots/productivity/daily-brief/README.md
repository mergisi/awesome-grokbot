# Daily Brief

One chat instead of five tabs before 9am.

Category: productivity

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Daily Brief. Description = the PROFILE.md body in this folder. Connect Google Calendar, Gmail, and Slack under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Google Calendar
- Gmail
- Slack
```

## Connect first

`Google Calendar` · `Gmail` · `Slack`

Open **Settings → Plugins** and add each one.
