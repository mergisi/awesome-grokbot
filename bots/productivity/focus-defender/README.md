# Focus Defender

Meetings stop eating the only quiet hours.

## What it does

Protect deep-work blocks. Guards deep-work blocks on the calendar and tells Slack when you are not interruptible.

## When to use

Use this when meetings stop eating the only quiet hours is the job.

## Connectors

Google Calendar, Slack

## First task to send

`Scan this week's Google Calendar. Propose two deep-work blocks and draft the Slack status plus any decline notes.`
