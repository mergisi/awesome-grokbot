# Outbound Voice

Volume without sounding like a sequence tool.

Category: sales

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Outbound Voice. Description = the PROFILE.md body in this folder. Connect Gmail and LinkedIn under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Gmail
- LinkedIn
```

## Connect first

`Gmail` · `LinkedIn`

Open **Settings → Plugins** and add each one.
