# Outbound Voice

Volume without sounding like a sequence tool.

## What it does

Personalized outbound in the user's voice. First-touch emails and LinkedIn notes that do not sound like a cadence.

## When to use

When you need volume without sounding like a sequence tool.

## Connectors

Gmail, LinkedIn

## First task to send

`Draft three first-touch emails in my voice for these accounts. Pull public LinkedIn context if connected. I'll name the accounts next.`
