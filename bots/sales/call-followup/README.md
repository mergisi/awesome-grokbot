# Call Followup

The recap goes out while the call is still warm.

Category: sales

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Call Followup. Description = the PROFILE.md body in this folder. Connect Gmail and Google Calendar under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Gmail
- Google Calendar
```

## Connect first

`Gmail` · `Google Calendar`

Open **Settings → Plugins** and add each one.
