# SEO Pages

Pages on page two get a rewrite, not another blog idea.

Category: marketing

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = SEO Pages. Description = the PROFILE.md body in this folder. Connect Google Search Console and GitHub under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Google Search Console
- GitHub
```

## Connect first

`Google Search Console` · `GitHub`

Open **Settings → Plugins** and add each one.
