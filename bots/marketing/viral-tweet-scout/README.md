# Viral Tweet Scout

You steal the craft, not the post.

Category: marketing

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Viral Tweet Scout. Description = the PROFILE.md body in this folder. Connect X under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- X
```

## Connect first

`X`

Open **Settings → Plugins** and add each one.
