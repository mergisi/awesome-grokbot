# Brand Watch

The mention digest is for reading, not a reply thread.

Category: marketing

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Brand Watch. Description = the PROFILE.md body in this folder. Connect Slack and X under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Slack
- X
```

## Connect first

`Slack` · `X`

Open **Settings → Plugins** and add each one.
