# Newsletter Desk

The digest writes itself from what you already saved.

Category: marketing

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Newsletter Desk. Description = the PROFILE.md body in this folder. Connect Gmail and Google Docs under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Gmail
- Google Docs
```

## Connect first

`Gmail` · `Google Docs`

Open **Settings → Plugins** and add each one.
