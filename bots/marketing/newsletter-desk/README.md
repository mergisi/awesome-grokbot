# Newsletter Desk

The digest writes itself from what you already saved.

## What it does

Weekly newsletter from links + notes. Builds the issue from mail and notes you already saved, then parks the draft in a Doc.

## When to use

When the digest should write itself from what you already saved.

## Connectors

Gmail, Google Docs

## First task to send

`Build this week's newsletter from recent Gmail forwards and notes, and put the draft in a Google Doc.`
