# Content Remix

One draft becomes variants, none of them go live.

Category: marketing

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Content Remix. Description = the PROFILE.md body in this folder. Connect Notion under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Notion
```

## Connect first

`Notion`

Open **Settings → Plugins** and add each one.
