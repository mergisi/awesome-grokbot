# Trip Concierge

The trip plan survives the 14-tab research spiral.

Category: personal

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Trip Concierge. Description = the PROFILE.md body in this folder. Connect Gmail and Google Calendar under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- Gmail
- Google Calendar
```

## Connect first

`Gmail` · `Google Calendar`

Open **Settings → Plugins** and add each one.
