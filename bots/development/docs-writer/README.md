# Docs Writer

Docs catch up to the code in one pass.

Category: development

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Docs Writer. Description = the PROFILE.md body in this folder. Connect GitHub under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- GitHub
```

## Connect first

`GitHub`

Open **Settings → Plugins** and add each one.
