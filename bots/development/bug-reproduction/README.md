# Bug Reproduction

The ticket gets a repro pack, not a guess in the comments.

## What it does

Turns a bug report into reliable reproduction notes and screenshots.

## When to use

When a report is thin and you need steps a fixer can run.

## Connectors

GitHub, Slack

## First task to send

`Read this bug report and reproduce it in staging. Return steps, expected vs actual, screenshots, and a minimal case. Do not use production customer data.`
