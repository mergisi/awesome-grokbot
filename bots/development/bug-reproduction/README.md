# Bug Reproduction

The ticket gets a repro pack, not a guess in the comments.

Category: development

## The setup prompt

Copy [SETUP.md](SETUP.md) and paste it as the first message to a new Grok Bot (or into Description if the bot already exists).

```
Create this Grok Bot. Name = Bug Reproduction. Description = the PROFILE.md body in this folder. Connect GitHub and Slack under Settings → Plugins. Then send the First task from the README. Draft and research only. Do not send, post, pay, or contact anyone unless I ask.

Connect first:
- GitHub
- Slack
```

## Connect first

`GitHub` · `Slack`

Open **Settings → Plugins** and add each one.
